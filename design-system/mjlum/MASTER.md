# 麻雀諗 · 設計系統

本次按使用者要求修正原有百科網站範本。以 docs/guide.md 的產品規則為準，UI 不變更計分公式。

## 方向
Minimalism / Soft UI Evolution。淺色優先、實體牌桌單手操作、繁體中文（香港），不使用漸層、玻璃效果、表情圖示或裝飾動畫。

## 色彩
主色／焦點 #1E3A8A；主按鈕白字；背景 #F8FAFC；卡片 #FFFFFF；文字 #17243B；次文字 #475569；邊框 #CBD5E1；已選 #E8EEF9；正數 #166534；負數 #B42318。正負同時有文字／符號，不單靠顏色。

## 字體與間距
系統繁體中文無襯線；內文16/24、標題28/36、分數40/48，數字等寬，支援系統字體放大。4/8/16/24/32間距；圓角12–20；正文最大寬720。觸控至少48×48，主動作56高。淺邊框分組，不以陰影堆疊。

## 操作
底部四項：牌桌、記錄、找數、統計；食糊為牌桌主要動作，流局次要。其餘操作收進更多工具彈窗。進入功能顯示清楚返回，牌桌亦提供首頁入口。食糊順序為選玩家、從完整番數選項選擇、選自摸或出銃者、核對後確認；不顯示多餘的問號列及付款方式標題。
金額數字欄位提供數字鍵盤及明確完成／取消，支援小數與分數，不截斷精確值。開關使用原生 Switch，選項使用已選底色及勾號；起糊及滿糊共用一條雙端滑桿，支援無障礙增減。紀錄、牌局設定與番數表使用有欄名及格線的表格，數字對齊；過寬表格可橫向捲動。分數卡片不提供精確值展開。流局以牌桌上方的彈窗確認。所有頁面統一安全區及頂部留白。

## 無障礙
互動有語意、名稱、選中／停用狀態；焦點3px深藍，按下有底色反饋；使用Lucide SVG。遵守安全區及鍵盤避讓，無裝飾動畫。淺色是本次交付主題，深色不宣稱完成。

## 品牌圖示
原創圓潤紅中麻雀牌角色：白色牌面、深藍輪廓及笑臉、深綠牌底。App 圖示使用深藍實色背景，首頁與啟動畫面使用透明角色。向量來源為 `app/src/constants/brand.ts`；以 `npm run generate:brand` 匯出 iOS、Android、網頁及啟動畫面素材。
