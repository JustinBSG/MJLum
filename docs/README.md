# 麻雀諗 documentation

The GitHub repository for this app is [MJLum](https://github.com/JustinBSG/MJLum).

麻雀諗 is a table scorekeeper for in-person Hong Kong Mahjong. It is not a tile game. The app name is only 麻雀諗 (the third character is U+8AD7).

This release scores Hong Kong mahjong only. 台灣麻將, 日本麻雀, 碰槓牌（跑馬仔）, and 港式台灣麻將 wait until after the second release. The second release is the wireless scoreboard on a television.

## How facts are labelled

- **麻雀諗 product decision:** a rule decided for 麻雀諗.
- **Taken from the local reference:** behaviour established by the local reference. Do not copy that app’s UI.
- **Unspecified:** not demonstrated and not decided. Do not invent a formula to fill the gap.

Ads in the local reference are not 麻雀諗 features. 麻雀諗 has no ads. Screen layout is not specified here.
