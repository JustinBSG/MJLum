## 發行內容

- 香港麻雀預設及自訂玩法、番數分數表、起糊／滿糊共用滑桿及數字鍵盤。
- 玩家入座、莊家及圈風／手數進度、換人、換位與未入座玩家卡片。
- 食糊、自摸、一炮多響、半銃、詐糊及受現有規則支援的包付情況；確認前顯示本手預覽。不支援的組合仍拒絕計分。
- 彩池供款、領取及向所選在座玩家分配；找數顯示非零淨額及未分配彩池，不產生轉帳配對。
- 本機牌局紀錄、事件／分數／綜合表格、還原、重做、既有記錄修改及牌局生命週期操作。
- 統計、稱號及雷達圖；使用既有精確分數與統計引擎。
- 1–9 粒擲骰，加入短暫翻滾動畫、每粒點數、總點數及方位；支援減少動態效果。
- 原創可愛紅中麻雀圖示、啟動載入畫面、繁體中文（香港）及淺色牌桌介面。

## 驗證及界線

發行檢查：Expo lint、TypeScript、既有 103 項測試及 iOS／Android JavaScript bundle 匯出。使用者已確認目前 UAT 完成。

此紀錄代表原始碼發行，沒有宣稱已產生簽署安裝檔或完成 App Store／Google Play 上架。完整原生啟動畫面、系統圖示及平台原生行為仍以獨立安裝版為準。網頁只供介面預覽，資料存於記憶體。

電視無線顯示屬第二次發行；其他麻雀地區玩法、雲端同步、備份及多裝置同局不屬本次範圍。詳細計分以 [guide.md](../guide.md) 的產品決定及程式驗證為準。
