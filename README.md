# 麻雀諗 · MJLum

香港麻雀實體牌桌記分工具，使用 Expo／React Native，介面為繁體中文（香港）。

目前版本：**Version 1 · Release 1（1.0.0，Build 1）**。UAT 已完成，發行來源為 `uat` 的 `233c446`，正式原始碼位於 `main`，版本標籤為 `v1.0.0`。

## 開始使用

在專案根目錄以 PowerShell 執行：

```powershell
cd app
npm ci
npx expo start --go --lan
```

保持 Terminal 運行，手機與電腦連接同一 Wi-Fi，再掃描 Terminal 顯示的 QR Code。需要清除舊快取時加上 `--clear`。
